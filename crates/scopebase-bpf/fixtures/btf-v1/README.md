# BP09 bounded-BTF corpus (btf-v1)

Independent BTF v1 vectors for the `scopebase-bpf` `btf` feature. All bytes
are generated by `generate_vectors.py` (an independent little-endian BTF
writer; no donor or parser code imported). Regenerate with
`python3 generate_vectors.py`; verify with
`python3 generate_vectors.py --check`.

## B04 trial corpus slice binding (BP09 executor choice)

- **T1 rival-name twins**: `images/base-rivals.bin` (two `dup` INTs plus a
  pointer) with the split module `images/split-extra.bin`. Mirrors the SB02
  probe population without reusing its bytes.
- **T2 admitted linkage image**: the BP02 `btf-u32-u64.bin` fixture
  (referenced from `tests/fixtures/bp02/`, not duplicated here).
- **T3 authored graphs**: `images/shapes.bin` (composites, enums, arrays,
  functions, bitfields, anonymous members, declaration tags, narrowed INTs,
  forward/float/enum64 forms, rival composites, qualified alias),
  `images/maps.bin` (DATASEC/VAR map linkage with orphan/broken controls),
  `images/cycle.bin` (wrapper cycle, dangling and void references).
  Hostile truncation/corruption mutants are derived by byte surgery in
  `tests/btf.rs`, not stored.

## Files

- `images/*.bin`: corpus images above.
- `graphs.json`: per-image type-graph log (id, kind, name offset, vlen,
  kind flag, size/type word, aux bytes) plus string tables; the
  independent oracle for name/id reachability.
- `expected.json`: query-level expectations (shapes, extents, canonical
  ids, function and map linkage) asserted field by field.
- `manifest.json`: generator provenance with per-file SHA-256 and sizes.
