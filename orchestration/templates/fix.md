# Fix assignment template

Controller supplies the original brief/report, current exact HEAD, review file, verbatim accepted findings, ruling IDs, allowed changed files and the named covering tests. Preserve prior evidence and append a new attempt.

Fix the accepted defects with a regression/control at the intended layer. Record a genuine spec/plan conflict before changing behavior. Do not silently expand scope, weaken assertions, suppress failures or repeat irreversible effects. If a finding is already fixed, point to the exact changed bytes and test evidence. Return commits, findings addressed/open, commands/results, assertion changes and resource custody. The scoped reviewer checks this changed range and any new breakage.
