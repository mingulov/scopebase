# Worker report template

Status: DONE / DONE_WITH_CONCERNS / BLOCKED / NEEDS_CONTEXT (choose one).

Record task and attempt ID; goal/spec/plan bindings; base and final full SHAs; commit list and owned files; exact commands, exit status and semantic results; independent oracle and red/control evidence paths; required environment/case coverage and unexecuted checks; decisions and reasons; assertion/fixture changes needing a controller ruling; concerns and new TODO proposals; and pending resources with owner and cleanup state.

This report is an administrative handoff. DONE means the worker believes its deliverable is ready for review. The controller separately records independent review, exact-candidate verification and task acceptance.
