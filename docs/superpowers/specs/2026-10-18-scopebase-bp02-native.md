# BP02 native authority, syscall and resource contract

Date: 2026-10-18. **Status: controller-ratified contract, including independently approved BP02-R1.** These are required implementation rules, not observed product behavior or runtime qualification. The [map contract](2026-10-18-scopebase-bp02-maps.md) owns public signatures, pure algorithms and decision reasons; the [verification contract](../plans/2026-10-18-scopebase-bp02-verification.md) owns required fixtures, controls and acceptance cells. Exact source/dependency admission, implementation dispatch and live-resource admission remain controller-owned.

## Platform and trust

Compile the native owner/API only for `all(target_os = "linux", target_arch = "x86_64", target_env = "gnu", target_pointer_width = "64", target_endian = "little")`. Pure topology/geometry remain portable. There is no unsupported stub claiming implementation on other targets. Admission on the compiled platform requires the operations below to succeed; it does not consult a kernel version string, config file, qualification report, caller attestation, boot-ID text, affinity or online count as authority.

The safe syscall boundary assumes an ABI-conforming Linux kernel: possible CPU IDs are fixed after boot discovery, sysfs possible describes the same global mask used by the actual perCPU map syscall, map metadata and linked BTF are immutable while retained, kernel filesystems implement their reviewed root/inode semantics, and the kernel obeys the documented syscall pointer extents. On the admitted x86_64 ABI, base PAGE_SIZE is 4096. Process restoration onto a different kernel, an ABI-violating kernel or interposer, and application unsafe code closing private FDs are outside this contract. Ordinary process lifetime plus held kernel objects supplies boot continuity; no public token can attest it.

This is an ordinary operating-system trust boundary, not a claim that every Linux build has been qualified. The implementation's runtime target set is the compiled ABI satisfying these preconditions. The qualification ledger separately lists actual source/config/build/fixture bytes tested. No selected version (5.15.223, 6.12.113 or 7.2.11), `uname`, or successful load adds a tested configuration. Unknown syscall/source facilities fail closed. A known nonconforming platform needs a different, reviewed atomic extent mechanism before admission; before/after comparisons alone never bound a growing mask.

## Syscalls and unsafe boundary

Change the library lint from `forbid(unsafe_code)` to `deny(unsafe_code)` and add `deny(unsafe_op_in_unsafe_fn)`. Only private `maps/native.rs` has `#[allow(unsafe_code)]`. Its safe-to-parent wrappers require private checked owner/extent types, not public raw FDs or arbitrary lengths. Safety comments bind every pointer, extent, initialized byte, FD ownership and immutable-mask assumption. No public unsafe escape hatch or caller backend exists.

Use rustix 1.1.5 with `std,fs,process,thread,linux_4_11` for openat2, statx, fstatfs, readlinkat, pread, getpid/gettid and OwnedFd operations. `linux_4_11` selects direct statx and avoids its compatibility probe/cache changing errno or effect accounting. A blocked/absent operation refuses; there is no openat/stat fallback. Use libc 0.2.191 only for `syscall(SYS_bpf, ...)`, immediate errno capture and adopting a newly returned BTF FD. All flags/padding are initialized; use explicit byte arrays and little-endian field access, with u64 pointer encodings on this target. No typed alias into Vec storage.

Production BPF commands are LOOKUP_ELEM=1, GET_NEXT_KEY=4, OBJ_GET_INFO_BY_FD=15 and BTF_GET_FD_BY_ID=19. Production performs no map create/update/delete, BTF load, program load, attach, mount, namespace, privilege/limit/sysctl/signal change or child creation. Fixture-only operations are described separately.

| Command | Attribute passed | Exact output storage |
|---|---|---|
| OBJ_GET_INFO_BY_FD | 16 bytes: fd u32 at 0, info_len u32 at 4, info pointer u64 at 8 | initialized map-info [u8;88], or BTF-info [u8;32] |
| GET_NEXT_KEY | 24 bytes: map_fd u32 at 0, zero pad at 4, key u64=0 at 8, next_key pointer u64 at 16 | initialized admitted key-size Vec |
| LOOKUP_ELEM | 32 bytes: map_fd u32 at 0, zero pad at 4, key pointer u64 at 8, value pointer u64 at 16, flags u64=0 at 24 | initialized admitted full perCPU extent Vec |
| BTF_GET_FD_BY_ID | 4 bytes: actual map btf_id u32 at 0 | nonnegative newly owned FD return |

Use syscall attribute sizes above, not sizeof an unrelated full union. GET_FD_BY_ID's last used field is btf_id; passing four bytes makes later union members irrelevant. Every fd integer conversion is checked. Non-FD commands require return0; unexpected positive returns are Backend with no invented errno. BTF FD return must fit nonnegative RawFd. A private invalid-FD syscall test constructs the numeric attribute directly; it never creates an invalid Rust OwnedFd/BorrowedFd. No implicit EINTR retry. Destruction closes owned descriptors without retry; close does not prove kernel-map destruction or producer retirement.

## Metadata and real map identity

Constructor precedence is the sequence here. A failure stops subsequent stages and preserves earlier native errno.

1. Check supported expected map type (5 hash, 6 array), positive key/value/max_entries, power-of-two alignment in 1..=8, value size representable as u32, and nonzero expected BTF type IDs if Some. Invalid scalars are InvalidInput/Admission; u32 conversion failure is Overflow/Admission. Unsupported expected type or required flag bits is Unsupported/Admission. No schema digest is forbidden; it is a caller label.
2. Require input_bytes >= 88 and charge one backend work unit before OBJ_GET_INFO. Use a zeroed [u8;88]. Native error uses Metadata stage. Require returned info_len in 76..=88, else Incompatible/Metadata. Decode only fields present. Offsets: type 0, id 4, key 8, value 12, max_entries 16, flags 20; ifindex 40, btf_vmlinux_value_type_id 44, netns_dev 48, netns_ino 56, btf_id 64, key_type_id 68, value_type_id 72. If len >=80, decode btf_vmlinux_id at 76; if len >=88, decode map_extra at 80. An absent tail on older kernels is accepted for these two ordinary map kinds, not invented as evidence for a feature that requires that tail.
3. Refuse actual bloom (30) or any type outside 5/6 as Unsupported/Metadata immediately, before extent arithmetic, heap allocation, topology work, key witness or value lookup. Metadata query itself is necessary to learn actual kind and is explicitly permitted. Then compare expected type/key/value/max_entries exactly (Incompatible/Metadata); require nonzero actual map id. Require array key_size=4. Refuse nonzero ifindex, netns_dev/netns_ino, btf_vmlinux_value_type_id, present btf_vmlinux_id or map_extra as Unsupported/Metadata.
4. Supported stored flags: array `0x180` (RDONLY_PROG, WRONLY_PROG); hash `0x1c1` (those plus NO_PREALLOC and ZERO_SEED). Require actual flags to contain no other bit (Unsupported/Metadata) and `(actual & required_flags) == required_flags` (Incompatible/Metadata). These are reader-safe semantics, not permission to write. FD-level RDONLY/WRONLY flags are not reported as map flags; actual next-key/lookup permission checks decide readability. Do not infer access from metadata.
5. Require key_size <=65,536 and <=input_bytes. Apply retained/work caps, allocate/zero exact key scratch and issue GET_NEXT_KEY with NULL current key. Success or ENOENT proves a real readable map; discard the key. Any other errno fails Metadata. This witness is essential because OBJ_GET_INFO also accepts program/link/BTF objects. Kernel `__bpf_map_get` rejects a nonmap before writing, while an actual map's own immutable metadata supplies the key size. The witness does not enumerate or modify public map state. Drop its scratch before BTF/topology allocation.
6. If BTF is required, compare actual nonzero btf_id and actual key/value type IDs with expected; mismatch is Incompatible/BtfQuery. Execute the bounded BTF algorithm below. If None, do not acquire BTF or claim semantic schema validation.
7. Acquire live topology internally. Check native geometry from actual value_size and that topology, with extent <= min(i32::MAX, isize::MAX, u32::MAX, input_bytes) and retained capacity remaining after topology. A mathematically representable extent above the native ABI bound is Unsupported/Admission, above caller byte/capacity budget is LimitExceeded/Allocate. No caller CpuTopology can reach this step as authority. All allocations use checked arithmetic and fallible reserve.

After construction, metadata, BTF binding and geometry stay fixed for the held actual FD. No numeric map id, FD integer, report or filesystem path can replace it. Closing/reusing an external duplicate does not replace our reference. Other holders may change values; lookup promises a kernel read, not an atomic snapshot across lanes or producers. Raw padding is opaque bytes; byte-buffer alignment does not permit typed references.

## Linked BTF image

Implement Some fully in BP02. `ArtifactId` is SHA-256 of exact raw BTF image bytes returned for the map's linked BTF object. It carries no semantic type proof. Get a private BTF FD using the actual btf_id. The retained map keeps that object alive, so the ID cannot legitimately be reused between metadata and lookup. Native denial remains Denied/BtfQuery with errno, not an unsupported-success fallback.

First OBJ_GET_INFO on this BTF FD uses 32 initialized bytes with btf pointer/size and name pointer/length all zero. Require returned length 32, matching id, kernel_btf=0 and positive size. Require size <=16 MiB, <=input_bytes, <=isize::MAX and available retained capacity. Allocate exactly this size using fallible reserve, check actual Vec capacity, zero it, and issue a second info query with btf pointer/size set; keep name pointer/length zero. Require same id, size, kernel_btf and 32-byte info length on return. Changed values are Changed/BtfQuery; an unsupported kernel BTF object is Unsupported/BtfQuery. Hash exactly size bytes with sha2=0.11.0 and compare expected ArtifactId. Wrong digest is Incompatible/BtfQuery. Discard the bytes and BTF FD after comparison; retain only immutable map metadata/expectation. No BTF graph/name/layout parser or split-BTF resolver is introduced (BP09). Immutable bytes and equality checks, not a second metadata fetch alone, justify the bounded copy; the BTF syscall also limits copying to supplied size.

## Authentic topology and task context

Retained `LiveCpuTopology` state: immutable CpuTopology, Limits, original sysfs root, procfs root, possible attribute, current-task directory and thread-self O_PATH symlink; initial pid/tid; identity tuples; exact original authenticated thread-self text in a private [u8;64] plus usize length; and a private Cell invalidation flag. Five FDs are retained. ValidatedMap adds its map FD. Both owners are !Send and !Sync using PhantomData<Rc<()>>, with no Clone/serde/import/path/reader constructor or exposed FD. Pure types have no live authority. The thread restriction reduces task-identity ambiguity and can be relaxed only by a separately tested contract.

An identity tuple is `(stx_dev_major, stx_dev_minor, stx_ino, stx_mnt_id, file-type)`. Require returned statx mask TYPE|INO|MNT_ID and a nonzero mount id; unavailable fields are Unsupported, never filled from zeros or fallback. Use statx EMPTY_PATH on held descriptors. A retained mount prevents its mount-id reuse during this owner lifetime.

Acquisition requires input_bytes >=4096. Open absolute `/sys` and `/proc` using openat2 with O_PATH|O_DIRECTORY|O_CLOEXEC and NO_SYMLINKS|NO_MAGICLINKS. The one transition into each root mount is intentional, so root acquisition omits NO_XDEV. fstatfs must be SYSFS_MAGIC 0x62656572 / PROC_SUPER_MAGIC 0x9fa0 respectively; statx must show directory and inode 1. Reviewed Linux's full root has that inode, while a subtree does not. Full-root bind of that same genuine root is allowed at acquisition; it has the same trustworthy contents. A fake ordinary filesystem, symlink root, subtree presented as root, or missing identity field refuses Unsupported/Admission (native permission/missing-path errors retain their categories).

Open relative paths beneath retained roots with BENEATH|NO_XDEV|NO_SYMLINKS|NO_MAGICLINKS. Open `devices/system/cpu/possible` O_RDONLY|O_CLOEXEC; require regular file, matching root dev/mount identity. Pin `thread-self` with O_PATH|O_NOFOLLOW|O_CLOEXEC (the documented final-symlink exception to NO_SYMLINKS); require symlink on the original proc mount. `readlinkat` with empty pathname on this held symlink goes to the kernel-generated current-task link. Use fixed [u8;64]; reject full/truncated results. Admit only positive decimal u32 `tgid/task/tid`, with no extra bytes, slash or dot components. Open that exact numeric directory beneath proc root using the same constrained flags and retain its statx tuple. The proc mount may refer to an ancestor PID namespace; do not compare link text to getpid numerically. Record getpid/gettid separately. Retain the exact validated initial thread-self bytes and length without normalization, and retain the original task directory as a kernel-object lookup anchor. A pinned proc inode number is not unique task identity: get_next_ino wraps and does not reserve held inode numbers. Numeric inode tuples remain source-consistency checks only.

Read possible using pread into one fixed [u8;4096], increasing offset on short reads until EOF or the ceiling. Require observed length 1..=4094, last byte newline and an explicit subsequent EOF. Refuse every output of 4095 bytes or more, not just equality, before parsing/native value copy. Refuse missing newline as Malformed/Read and reached ceiling as LimitExceeded/Read. A syntactically valid truncated prefix is not authority. This fixed conservative ceiling is valid on the admitted 4096-byte native platform and is not a rule for enabling other page-size platforms. EINTR is an error; no unbounded retry. Parse with max ID 65535/count 65536. Retain exact original possible bytes and sorted IDs.

Read authenticated `devices/system/cpu/online` via a fresh constrained open and the same complete-read rule; parse and verify its IDs are a subset of possible. Do not use its count for geometry. Online/offline transitions may change this diagnostic set and are permitted if it remains a valid subset; a race causing malformed/inconsistent evidence refuses. No fallback to present, configured CPUs, sysconf, affinity or a smaller set exists.

Before completing acquire, and before/after every successful value lookup or lookup ENOENT, run revalidation: compare pid/tid; reopen/authenticate current `/sys` and `/proc` roots and compare their retained tuples; open fresh constrained possible, thread-self and numeric current-task directories and compare tuples with retained owners; reread original possible from offset zero and require exact bytes/IDs; authenticate fresh online and check subset. Close temporary FDs promptly. Add the exact original-task continuity phase below before this revalidation succeeds; tuple equality alone is insufficient. Do not replace the retained snapshot or saved task text. This detects fork, including same local PID/TID plus colliding inode tuples, changed sources and observed mask changes. It establishes continuity at each check, not continuous observation between checks or arbitrary ABA detection. A namespace change leaving exactly the original task and authentic source authority is harmless to this geometry contract; unrelated namespace/credential policy belongs to capability/attachment contracts. No namespace-magiclink attestation is introduced.

Observed identity/mask differences are Changed/Read; context pid/tid/task differences are Changed/Admission. Every failed attempted revalidation invalidates that owner (including inability to finish for denial, budget or I/O), while returning its original precise error. Subsequent methods return Poisoned/Admission and never refresh. Argument/budget admission failures before starting revalidation do not invalidate. A newly acquired owner is the recovery route. On initial acquire, preserve the underlying error category instead of Changed where no earlier identity exists.

### BP02-R1: exact original-task continuity phase

Run this private phase on acquisition completion and each pre/post revalidation, after closing all other validation temporary FDs. It does not produce a public authority type or change any API.

1. Read the current kernel-generated thread-self bytes through the **original held genuine thread-self symlink**, using empty-path readlinkat and the existing fixed 64-byte temporary. This is the same retained proc namespace in which the original text was obtained. Before a successful comparison, charge work by the current returned byte length, then require exactly the saved length and byte-for-byte equality with the saved validated original text. Any unequal result, including a full/truncated 64-byte result, is Changed/Admission; never normalize, replace the saved text or compare its numeric values to native getpid/gettid. Equality with the originally validated text already supplies its grammar validity. A readlinkat error retains the existing native kind/errno with Read stage. A previously captured initial text changing during acquisition completion is also Changed/Admission; no owner escapes that failed acquisition.
2. Open literal `stat` **relative to the original held task-directory FD**, using openat2 with BENEATH|NO_XDEV|NO_SYMLINKS|NO_MAGICLINKS and O_RDONLY|O_CLOEXEC. Never use a freshly resolved numeric task-directory FD as this probe anchor, an absolute proc pathname, or an imported/passed task FD. Authenticate the opened stat FD with statx EMPTY_PATH: retain the existing required TYPE|INO|MNT_ID evidence rule, require regular-file type and the original proc device/mount identity. Its numeric inode is not a continuity proof and need not equal a previous stat inode.
3. Initialize a one-byte private buffer, then perform one fresh pread at offset zero with request length exactly one. Require return count exactly one. Discard the byte without parsing, exposing or logging stat content and close the temporary FD on every path. Every probe starts with a new open-file description: do not retain, duplicate, rewind or reuse a previously read stat FD/seq-file buffer. Open/statx success is not a substitute for the read. There are no retries or extra stat reads.

Why this is sufficient under the existing kernel ABI: the held original task directory retains the original kernel PID object. Its relative lookup and fresh proc stat show callback resolve that object, not an arbitrary replacement with the same numeric PID. A live original task prevents another task from simultaneously owning the same numeric identity in that same proc namespace; exact saved text therefore distinguishes a different live task even if all inode tuple fields collide. If those numbers are reused after the original task is gone, the fresh original-anchor stat probe refuses. A fresh read is necessary because getattr can succeed without a task and a reused seq-file description may hold old output. The source chains are bound in `/home/user/src/m/bpfscope/.scopebase/controller/bp02-preparation-20261018/input-bindings-v2.json`: fs/proc/base.c's ONE/stat wiring, proc_single_show, proc_pid_make_inode, pid_getattr, proc_pident_lookup and proc_tid_base_lookup; fs/inode.c's wrapping get_next_ino. This changes no global possible-mask/extent assumption.

Error precedence for this phase is fixed:

| Event | Existing admitted owner | Initial acquisition, no accepted owner |
|---|---|---|
| Current thread-self bytes differ from the saved validated bytes | Changed/Admission, errno None | Changed/Admission for this observed difference; no owner returned |
| Stat source type/device/mount differs; constrained stat traversal yields EXDEV/ELOOP | Changed/Admission; preserve actual errno if there is one | Unsupported/Admission; preserve actual errno if present |
| Fresh original-anchor stat open/statx/pread yields ENOENT or ESRCH | Changed/Admission, preserve that exact errno even for pread | Existing native mapper at the operation stage: ENOENT -> Disappeared; ESRCH -> Backend under the unchanged generic mapping; preserve errno |
| Fresh stat pread returns zero (EOF) | Changed/Admission, errno None | Malformed/Read, errno None |
| Other open/statx failure, including EPERM/EACCES, ENOSYS/EOPNOTSUPP or missing required statx fields | Existing precise native/evidence kind with Admission stage | Same kind/stage; no owner returned |
| Other pread failure, including EPERM/EACCES or EINTR | Existing native kind with Read stage and exact errno; no retry | Same kind/stage; no owner returned |
| Impossible return count greater than the one-byte request in a model/backend | Backend/Read, errno None | Backend/Read, errno None |
| Work exhaustion or checked arithmetic failure | LimitExceeded or Overflow at the operation's stage before its effect | Same precise category/stage; no owner returned |

The existing native mapper remains unchanged globally: EPERM/EACCES -> Denied, ENOSYS/EOPNOTSUPP -> Unsupported, ENOENT -> Disappeared except specified operation overrides, other errnos -> Backend. Missing statx fields remain Unsupported/Admission. Text comparison/copy work and stat open/statx use Admission stage; readlinkat/pread and one-byte initialization/read-request work use Read stage. Earlier errors stop the phase; later checks cannot overwrite them. Every failed attempted revalidation poisons the admitted owner, returns the first precise failure and publishes no sample/caller output. Subsequent operations return Poisoned/Admission. Admission failures before revalidation starts retain their existing nonpoisoning rule. Lookup success and ENOENT require this postcheck; a prior non-ENOENT map-lookup error returns unchanged and skips postvalidation, so no later task error masks its errno.

Accounting delta: saved [u8;64] plus usize length is fixed owner storage, and the probe uses one additional fixed byte. Include both in the existing 32-KiB declared-buffer review; there is no new dynamic retained capacity. At initial capture, charge 64 units for saved-slot initialization and n units before copying the n validated bytes. On every comparison charge the current returned n bytes before equality testing, including a different-length outcome. Existing readlinkat/current-buffer charges remain. Each stat openat2, statx and pread attempt costs one backend work unit; charge one unit for the one-byte initialization and one for the one-byte read request before those operations. On a complete successful new probe the additional backend/one-byte work is therefore 3+1+1, plus the text comparison, without resetting the public-operation budget. Stop before each effect when its charge fails. The one returned input byte fits under the already-required 4096-byte native input capacity; there is no new byte-cap exception.

There is one extra **temporary** FD and zero extra retained FDs. This phase runs with other validation temporaries closed: at most 6 owned FDs for a standalone LiveCpuTopology during the probe, or 7 including ValidatedMap's map FD. Existing totals remain 5/6 retained and at most 12 owned overall. Close the temporary stat FD even if work is exhausted, using existing cleanup-outside-budget rules. Production adds no syscall class, mutation, process/namespace control or new authority.

Fresh source checks detect substitution but the held authentic source plus immutable global mask bounds the native copy even if a mount changes between checks. No source pathname is re-resolved inside the native value-copy function. No legitimate process survives a kernel reboot with these FDs; restoration across kernels is outside the admitted route.

## Lookup and output commitment

Order: sticky-state check; exact key length (InvalidInput/Admission); input cap; lookup_into destination length (LimitExceeded/Admission with required_size=full extent); retained-capacity admission; pre-revalidation; fallible scratch allocation/capacity verification and zero initialization; one actual lookup; post-revalidation on success or ENOENT; output commitment. Wrong key/short destination causes zero topology queries and zero value lookups. All work/capacity checks occur before the corresponding positive operation.

The actual syscall exclusively borrows initialized scratch of at least the proven extent and holds map/topology owners for the whole call. Non-ENOENT syscall error returns immediately as Read with original errno; do not replace it with a post-check error. It publishes no scratch. ENOENT is None/false only after successful post-revalidation; success similarly publishes only after that check. No partial syscall result can modify caller output. lookup_into copies exactly extent bytes on success, leaves any tail untouched, and leaves every byte unchanged on false/error. lookup returns ownership of the scratch Vec on success; it is not cached in the map. Mandatory array diagnostic consumers treat None as an error, never healthy zero. The public API deliberately has no raw pointer or needed-size output that could alias storage; C alias rules remain NX05's work.

## Budgets, resource bounds and errors

Constants: pure source <=65,536 bytes, CPU IDs 0..=65,535, count <=65,536; native complete cpulist <=4094 bytes, key <=65,536 bytes, BTF <=16 MiB, value extent <=i32::MAX and caller limits. All additions/multiplications/conversions are checked, including capacity sums and work. These limits bound bytes, not elapsed syscall time.

`Limits::input_bytes` bounds each individually admitted external byte object (caller key, complete cpulist including newline, BTF image, perCPU returned extent). It is not an aggregate process-traffic budget. Native acquisition additionally requires room for the fixed 4096-byte bounded read window and metadata requires 88 bytes; this makes zero input capacity fail before the first relevant read. Fixed-size identities/attributes are bounded by the contract. `sites`, `live_links` and `pending_retirements` are unused by this nonattachment component and are not repurposed; zero is valid for them.

`retained_bytes` bounds the sum of live dynamic-buffer logical capacities owned by this operation/owner: `4 * ids.capacity() + source.capacity()` for each retained topology, plus any temporary topology, key witness, BTF image or value scratch still alive. Caller input/output allocations are excluded. Constructor phases discard key/BTF scratch before topology retention; lookup adds only value scratch and bounded validation temporaries. Preflight requested capacity plus existing charges before reserve; use try_reserve_exact; verify actual Vec capacity and aggregate charge immediately afterward, dropping an overgrant before initialization/use. Allocation error/overgrant is LimitExceeded/Allocate. This bounds admitted logical capacities; allocator bookkeeping/usable-size over-allocation and transient failed allocation attempts are not a hard RSS guarantee. Declared fixed byte-buffer storage on an active native call path totals at most 32 KiB; scalar state/FD tables are separately bounded and reviewed. Check declared helper-buffer sizes; this is not a bound on compiler/ABI stack overhead. No unbounded cache or recursion.

Use a per-public-operation WorkBudget initialized from work_steps, including all nested acquisition/revalidation; never reset it inside a constructor/lookup. Charge before each operation: each attempted backend syscall=1; byte initialization/copy/compare/hash=n; parse CPU text=`3*n + count` (two bounded scans, retained-byte copy and ID emission allowance), online subset merge=`possible_count + online_count`; fixed 88/32-byte metadata decoding charges that many bytes. Treat path/identity scalar checks as bounded constant work already included in backend units. Charge 3*n before the first bounded parser scan; validation discovers count with checked arithmetic and charges count before the second-pass ID emission, never performing uncharged expansion. Native read loop charges each attempt and bytes requested before the read, releases no work charge on short result; at most 4096 positive one-byte iterations plus EOF before ceiling refusal. Fixed read window is zeroed/charged once per source. Checked work-counter overflow is Overflow at current stage; exhausted budget is LimitExceeded at current stage. Cleanup close operations run even after budget failure and are outside work admission so ownership is never leaked merely to honor a cap. No retries, cumulative process-wide quota, deadline, allocator-overhead bound or syscall cancellation promise is implied.

At most 5 retained FDs per LiveCpuTopology / 6 per ValidatedMap and at most 12 total owned FDs including validation temporaries; sequence temporary opens/drops to enforce this bound. BTF retrieval happens before live topology. No FD duplication is required. Existing caller aliases are outside this count. Every failure drops newly owned temporary objects; owned map fd is consumed even on constructor error. Map memory is kernel-owned and not charged to user-buffer retained_bytes; this reader does not create it.

Error mapping for native calls: EPERM/EACCES -> Denied; ENOSYS/EOPNOTSUPP -> Unsupported; ENOENT -> Disappeared except the explicit next-key/lookup absence cases and changed prior source; all other errnos -> Backend. Preserve exact errno and stage, without guessing verifier/capability/LSM causes. Source traversal EXDEV/ELOOP -> Unsupported initially, Changed if it replaces previously admitted authority. Short/missing required statx/map-info evidence -> Unsupported/Incompatible as specified, never zero-filled success. Native metadata/BTF data inconsistency -> Incompatible or Changed as above. Pure errors have no errno. Required_size is set only for short lookup_into output; no arbitrary error prints caller bytes/source paths. Use accepted BP01 OperationError API unchanged.
