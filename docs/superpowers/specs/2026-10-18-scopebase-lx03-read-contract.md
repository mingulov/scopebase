## Prerequisite interfaces and dependency semantics

Use `HeldFile: AsFd` directly; implement its read_all impl in the sibling read.rs without exposing held.rs::file. `StatObservation::from_stat(&rustix::fs::Stat)->Option<StatObservation>` is already crate-private and checks raw device/inode, nonnegative length, signed seconds and nanoseconds. Its getters and Eq compare exactly the required observation fields.

LX04 supplies `OperationControl::checkpoint(&self)->Result<(),ControlStop>` and `ControlStop::into_error(self, Stage, EffectSummary, ResourceCharges)->LinuxError`. Transfer the actual effect and charge state; do not rebuild zeroed context. Keep production clock/cancellation private, no generic latch. Any dead_code allowance removal is mechanical only. `ReadOps` must call the same production checkpoint, not an unrelated simulated control.

Local rustix 1.1.5 source was inspected at the paths/hashes in input-bindings.json. `io::pread<Fd:AsFd,Buf:Buffer<u8>>(fd,buf,offset:u64)` returns `io::Result<Buf::Output>`; with `&mut [u8]`, output is usize. The x86_64 linux_raw path calls pread64 once; no EINTR retry is hidden. The libc path casts offset to i64 and relies on errno for a negative value. Bind the accepted default Linux backend; do not claim a libc-forced or other-target runtime cell. Use plain pread, never preadv2's special current-offset value. The syscall permits only signed nonnegative offsets; all admitted/read offsets must remain <=i64::MAX. The Vec element-size bound requires requested size<=isize::MAX, so a successful admitted original length is at most isize::MAX-1 on x86_64. Underlying filesystems can impose smaller limits; preserve their errno.

## Exact execution, bounds and error order

Keep a private per-invocation operation record. It owns no native resource; HeldFile is borrowed for the whole call. Counters start zero, descriptor flags NotAttempted, cleanup NotNeeded. `attempted_operations == syscall_attempts` for read_all; `completed_operations` increments once for every successful explicit syscall including EOF. No count is refunded when a later check refuses. FD acquisitions, peak_new_fds and target mapping creation/retirement are always zero. Read bytes count successful kernel-delivered bytes including a positive sentinel, never requested bytes or initialized zeros.

1. **Entry:** initialize pure state; checkpoint with Stage::ReadFile. Pre-cancelled wins over deadline. Then reject max_read_calls==0 or >u64::MAX-3, or max_buffer_capacity==0 as ReadFile/InvalidInput, no source, no syscall/allocation. max_bytes==0 is valid.
2. **Initial fstat:** checkpoint immediately before effect; increment attempt/syscall, issue exactly one rustix::fs::fstat. Record success before post-call checkpoint. Failed syscall keeps source/classification regardless of checkpoint stop. On successful permitted continuation, require regular type, then convert to StatObservation. Nonregular => NonRegular; conversion failure => Malformed; no payload allocation.
3. **Initial readability:** checkpoint; issue/count exactly one rustix::fs::fcntl_getfl. Record result and post-check control with the same failed-call precedence. Refuse O_PATH or access mode other than masked RDONLY/RDWR as Unreadable. Never change shared flags/cursor; preserve O_APPEND/O_NONBLOCK/O_DIRECT. An unsupported O_DIRECT alignment may cause real pread EINVAL, which remains Inconclusive; do not silently switch descriptors, align with a new allocator, or weaken accounting.
4. **Admission:** compare observed size s to max_bytes first; excess => LimitExceeded(InputBytes). Compute s.checked_add(1), checked usize conversion, requested<=isize::MAX and requested<=max_buffer_capacity, and s<=i64::MAX; failures => LimitExceeded(BufferCapacity), no allocation/read. Check all conversions before allocation; never compute max_bytes+1. A separate private pure admission helper may accept synthetic u64 sizes so u64/usize overflow has an exercised refusal path, without constructing public stat evidence.
5. **Reservation:** checkpoint before allocation; record requested_capacity=s+1 immediately before the only `Vec::new().try_reserve_exact(requested)` attempt. Failure => Allocation with source None, requested set, granted=0, retained=0; no bytes/read calls. On success record Vec.capacity() before post-effect checkpoint. If control permits, refuse actual granted capacity>max_buffer_capacity as LimitExceeded(BufferCapacity) before initializing/reading. Allocator overgrant can occur transiently before this refusal; do not advertise a hard granted/RSS cap. Do not shrink/reallocate to hide it.
6. **Initialization:** initialize requested bytes directly in the reserved Vec, using resize in chunks<=65536 and a checkpoint before/after each chunk. No second read scratch buffer; fixed scalar/stat metadata only. These CPU writes and reservation are not explicit syscall/work-counter units. Initialization is bounded by requested and may be stopped between chunks, but allocator/kernel scheduling has no hard time bound.
7. **Each pread:** checkpoint; reject if read_calls==max_read_calls as LimitExceeded(ReadCalls) before the next syscall. Read at local offset initially zero, request `min(65536, (s+1)-offset)` into the already initialized Vec segment. Every request is positive; offset, request-end and positive-result addition are checked; backend success n>request is Malformed at the private seam, never memory-unsafely consumed. Increment read_calls, attempted and syscalls immediately before the syscall. Record success/completed and n bytes before post-call checkpoint. Real rustix validates buffer initialized output and the kernel cannot return n>request on a valid call; the seam check prevents a broken fixture from certifying behavior.
8. **Syscall result / EINTR:** a non-EINTR error returns its original source/classification, even if post-check observed cancellation/deadline. EINTR consumes work, never bytes/completed. If its post-check observes stop, return Inconclusive with that original EINTR; if it passes, retry through the next loop checkpoint and budget check. No retry after a terminal error. With an always-interrupted source and limit 3, exactly three reads occur and next admission returns LimitExceeded(ReadCalls), source None; no fourth call. A fresh cancellation at the next loop checkpoint can win there because the previous retryable attempt was already classified.
9. **Successful read interpretation:** post-call cancellation/deadline wins before semantic interpretation, with incurred bytes/calls preserved. Otherwise zero before offset==s => ChangedSource immediately; no retry/final stat. Positive bytes advance only the local checked offset. If offset>s, return LimitExceeded(InputBytes) when offset>max_bytes, otherwise ChangedSource; stop at the first observed positive sentinel, without final stat or more reads. Short positive results continue. Offset==s is not success: issue the one-byte EOF probe subject to ordinary work/control limits. A call that spans the remaining payload and sentinel can observe EOF only on a later zero return; success always has an actual zero return at exactly s. An empty file requires one zero-return pread at offset0/request1.
10. **Final fstat:** only after valid EOF; checkpoint then one fstat, counted and post-checked with failed errno precedence. A nonregular final type => ChangedSource. Failed conversion => Malformed. Require final StatObservation==initial (raw device/inode, length, mtime, ctime), else ChangedSource. No pathname lookup or caching.
11. **Publication:** truncate Vec length to s without shrinking capacity; checkpoint before Arc allocation; move the Vec into Arc (never Arc::from(Vec) into a slice). Record retained_capacity=granted only for the candidate result. Final checkpoint immediately before return, after Arc construction and all metadata validation. Stop drops this private result and reports retained_capacity=0; historical charges remain. Later cancellation after the final checkpoint may coexist with success. FileRead has no retained HeldFile; bytes survive its drop and are observations, not a handle to reread or attach.

For every error, drop all temporary buffer/Arc owners before returning its LinuxError; no returned partial payload. Cleanup NotNeeded describes absence of acquired native resources, not proof of successful close/unmap/detach. Allocation failure in Arc/control metadata or an aborting allocator is outside recoverable Allocation behavior. No lock or public callback is introduced.

**Read-stage syscall classification:** EACCES/EPERM=>Denied; ENOSYS/EOPNOTSUPP/EMFILE/ENFILE/ENOMEM=>Unavailable; ENOENT/ESTALE=>Disappeared; every other errno (including EIO/EBADF/EINVAL/EOVERFLOW/ESPIPE, and terminal EINTR)=>Inconclusive. Preserve raw errno and no dynamic source formatting. fstat/F_GETFL EINTR is terminal and not retried. Semantic refusals/control/work/allocation have source None, except the specified failed-call winner. Admission order and the successful-call post-check order above are part of the test contract.

**Bounds:** For admitted size s, requested payload storage is s+1; cumulative delivered bytes<=s+1; each request/initialization chunk<=65536; pread attempts<=max_read_calls; explicit syscalls<=max_read_calls+3. Success ordinarily requires ceil(s/65536)+1 preads if reads fill requested chunks, but short returns/EINTR increase actual work. Vec/allocator overhead, Arc metadata and kernel resources are not included in the payload cap. Concurrent operations add independently reserved/granted capacities. Clone shares one already charged capacity; summing identical per-allocation snapshots across aliases double counts and is not a pool ledger. This API implements no pool/global cap or durable counter epoch.

## Per-invocation seams and semantic tests

Private production `ReadOps` wraps fstat/getfl/pread/reserve/checkpoint and the exact loop above. Freeze these extraction boundaries: `read_all_with(held:&HeldFile, limits:ReadLimits, control:&OperationControl, ops:&mut ReadOps)->Result<FileRead,LinuxError>` owns the algorithm; `admit_size(size:u64, limits:ReadLimits)->Result<(usize,usize),LimitKind>` returns `(payload_len,requested_capacity)` after the admission checks; `ReadOps::charge_read(&mut self, max_read_calls:u64)->Result<(),LimitKind>` checks/increments read-call and aggregate attempt counters immediately before the actual pread (no callback/effect between charge and call). HeldFile::read_all creates a fresh production ReadOps and calls read_all_with. Post-call bookkeeping and control never refund this charge. Under cfg(test), an owned invocation fixture may override one syscall result, mutate a fixture at a named barrier, cap a real pread length, override before/after stat fields, arrange EINTR/error, or record allocation counts and requested sizes. Keep hooks and scripted callbacks test-only and local; no static/global hook, feature-visible alternate backend or public trait. Successful real-file fixtures should invoke actual syscalls except the named fault/short-return boundary. Injection into allocation must exercise the actual branch used for real reserve failure/overgrant; it must not return a preconstructed LinuxError. Barrier events need exact stage/call index and the oracle log must be maintained by the fixture, not copied from ResourceCharges.

The exact opaque-control seam, only under cfg(test), is `OperationControl::with_test_deadline(at:Instant, cancel:CancelToken)->Self` and `OperationControl::checkpoint_at(&self, now:Instant)->Result<(),ControlStop>`, both pub(crate), with the latter delegating to the existing checkpoint_using closure; it observes the same cancellation token and comparison code. The constructor wraps the supplied Instant in private MonotonicDeadline and calls the existing new constructor. ReadOps may hold `test_now:Option<Instant>` only under cfg(test); Some dispatches to checkpoint_at, otherwise it invokes unchanged production checkpoint(). Use per-invocation stage hooks to cancel the real token or advance this time after a chosen effect. There is no production/user clock injection and all existing privacy assertions remain. Root serializes this test-only adaptation with existing control tests. No sleeps decide ordering. Every blocking fixture runs in an owned outer-watchdog child and joins after explicit release; if the watchdog fires, report FAILED with child retirement status.

### Preserve the accepted FD fixture guard

Every new in-crate unit fixture that allocates FDs participates in the accepted `crate::FD_TABLE` guard, including read fault/race fixtures and any read-control fixture adaptation. Acquire the guard before the first fixture FD allocation and retain it until all fixture FD owners have closed and every worker has joined or child has been reaped. Arrange explicit drop scopes so the guard cannot be released first. A child thread must never reacquire this guard while its parent holds it and joins that thread; the parent's guard covers that worker's fixture lifetime. An owned watchdog child must likewise be joined/reaped and its parent-side fixture FDs closed before the parent guard is released. Preserve ordinary parallel Rust test-harness execution and existing no-refund assertions. This retains the accepted real parallel FD-reuse fix; it adds no production locking, serial test-harness flag or process-global product policy. Test-local source wrappers and package-mutant variants must preserve the same guard lifetime.
