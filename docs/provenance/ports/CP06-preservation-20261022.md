## CP02/CP06 correspondence

CP06 consumes accepted CP02 values without changing them: `LossFact`/`LossMagnitude` supply retained observations, `CappedLossSignal` supplies diagnostic signals, and the domain IDs, `Epoch`/`SourceRef`, units and `Count`/`CountBounds` supply identity and magnitude vocabulary. CP02's partition/conservation/interval machinery, CP03's folds, CP04's insertion gate and CP05's generation keys are used as specified, never reimplemented or weakened. Fifteen narrow donor subsets run as adapted regression vectors against these CP06 views; scalar 512/4096/8192/pool3 witnesses stay caller fixtures. The two delivered clients own materially different reducers and route by complete CP05 keys.
